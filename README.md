## ⚡ Features
- 🏠 **Real-Time Divar.ir Monitoring**: Continuously monitors new listings matching specific price, area, and neighborhood criteria.
- ⚡ **Instant Telegram Alerts**: Sends instant formatted notifications with direct links and photos the second a new listing appears.
- 🛡️ **Anti-Ban Architecture**: Request rate throttling and header randomization to ensure stable 24/7 scraping.
